# Evidence placeholders

This folder is for candidate-owned trial evidence only:

- workspace and billing screenshots;
- setup SQL output;
- catalog/schema/volume screenshot;
- compute and warehouse screenshots;
- upload source and row-count evidence;
- Bronze, Silver, and Gold samples;
- reconciliation outputs;
- AI/BI and Genie screenshots;
- Power BI screenshot;
- Lakeflow job graph and successful run;
- grants and cleanup evidence.

Do not put credentials, tokens, PII, or real customer data in this folder.
